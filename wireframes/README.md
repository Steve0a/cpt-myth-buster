# Wireframes

Low-fidelity wireframes for the main screens. Every screen uses the same shell: left sidebar, top bar with status pills, centered content column.

| # | Screen | What it shows |
|---|---|---|
| 01 | [Chat home](01-chat-home.svg) | Greeting, 4 suggested questions, Aug 2026 update banner, email signup bar, composer with disclaimer |
| 02 | [Answer with sources](02-answer-with-sources.svg) | Myth/Fact verdict, official quote + link, match score, feedback buttons, related questions |
| 03 | [AI fallback answer](03-ai-fallback-answer.svg) | Gemini answer from official text only, verified quotes, and the fallback flow |
| 04 | [CPT news check](04-news-check.svg) | Awareness notice, label legend, reviewed news cards with official comparison |
| 05 | [AI quality](05-ai-quality.svg) | Search test-set results, fallback safety check, Gemini vs. human, own classifier |
| 06 | [Email signup](06-email-signup.svg) | Signup form with consent, what you'll get, privacy note |

Red text on a wireframe is an annotation, not part of the UI.
